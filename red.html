Red Pill

Interactive Project Frontends & Local-Compute UI Hub

Each app under apps/<project>/ is a standalone static frontend hosted on GitHub Pages that can either run directly in your browser or connect to a local process running on your PC.

1. Local PC Compute Mode

Run heavy simulations or native code locally (e.g., http://127.0.0.1:8000 with CORS enabled) while using this site as your control panel and visualizer.

2. In-Browser Compute Mode

Run lightweight tools directly in the client browser using JavaScript, WebAssembly, or Pyodide with zero local installation required.
